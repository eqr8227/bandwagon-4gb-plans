## 4GB 够不够用：按用途给结论

结论先说：个人博客、开发测试这类用途，4GB 绰绰有余；跑 AI 模型、高并发下载中转这类活儿，买回来也是浪费钱。六类常见用途逐个过一遍。

**个人博客、小流量网站——绰绰有余。** WordPress 这类 PHP + MySQL 应用对内存要求不高，4GB 装完系统、数据库、缓存插件之后余量还很大；80GB SSD 装程序加几年文章数据库，用量通常只是零头；3TB 月流量对一个普通博客明显过剩。要留意的是线路：KVM 套餐默认走洛杉矶等地的普通机房，晚高峰国内访问会有波动。

**开发测试、学 Linux——本职工作。** 4 核足够同时跑 Docker 容器、数据库和 CI 任务，年付摊下来每天不到 $0.55，是折腾 VPS 的低门槛预算档。

**中小型外贸站、电商后台——配置够，线路要补课。** Magento、PrestaShop 这类后台 4GB 跑得动，但普通线路对国内客户的访问稳定性一般，建议套一层 CDN，或者直接选 CN2 GIA-E。

**跑代理——能用，但别当主力。** KVM 套餐支持 tun/tap，技术上没问题，只是普通线路晚高峰丢包明显，主力节点还是 CN2 GIA-E 省心。

**AI 模型部署、大模型推理——直接跳过。** 4GB 内存连小型量化模型都装不下，搬瓦工节点也没有 GPU，这个需求得换更大内存或带 GPU 的服务。

**下载站、视频站、高并发中转——会撞墙。** 3TB 流量在这种场景一两周就能吃满，1Gbps 标称带宽的实际表现也受线路质量限制。

## KVM 套餐迁移 CN2 机房：省钱的代价是流量

KVM 套餐支持在 KiwiVM 面板里自助迁移机房，目的地包括 CN2 线路的 DC3 CN2 GT 和 DC8 ZNET——等于花 $19.99/月 用上 CN2 线路，对比 CN2 GIA-E 4GB 的 $56.99/月，省下大约 65%。

三个限制要先想清楚：

1. **流量除以 3。** 标称 3TB 迁到 CN2 机房后只剩 1TB，其他配置不变；迁回普通机房，流量会恢复。
2. **迁不到顶级机房。** 可选的是 DC3 CN2 GT 和 DC8 ZNET，线路级别到不了 DC6/DC9 的 GIA-E，也去不了香港、日本。
3. **手动操作，IP 会换。** 在面板里选 "Migrate to another DC"，迁移期间停机几分钟到几十分钟，原 IP 不保留。

月流量用不满 1TB 的话，KVM 迁 DC3 是 4GB 预算里性价比最高的组合；跑下载、视频这类大流量业务就别折腾了。

不能。搬瓦工节点没有 GPU，4GB 内存连小型量化模型都加载不起来，想跑推理需要更大内存或带 GPU 的云服务。

### 月付和年付到底差多少钱？

80G KVM 月付一年 $239.88，年付 $199.99，年付省 $39.89（约 16.6%）；CN2 GIA-E 4GB 月付一年 $683.88，年付 $549.99，省 $133.89（约 19.6%）。确定长期用就年付，没想清楚可以先月付。

### 买小了能升级吗？

可以。KiwiVM 面板里随时能升级到更高配置，补差价即可，从低配起步再按需升级是安全的路径。

### IP 被墙了怎么办？

常规 KVM 套餐可以通过迁移机房更换 IP，原 IP 不保留，迁移期间短暂停机。部分特价套餐（比如 DC9 款）额外承诺 30 天内即使 IP 被封也能退款，购买前留意套餐页面的说明。

### 香港机房值不值得多花四倍的钱？

看用途。香港 CN2 GIA 在电信、联通、移动三网下的表现都排第一，但 4GB 年付 $1559.99 是 KVM 的近 8 倍。个人项目和一般建站，DC6/DC9 的 CN2 GIA-E 已经够稳；对延迟极度敏感的业务才需要认真考虑香港。
